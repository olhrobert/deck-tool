# Paragraph title

`<paragraph-title size="sm|md|lg" tone="strong" context="slide|surface">`. Sizes map to `components.paragraphTitle.size*`. Default size is `md`; default tone is `strong`.

Canonical markup: `design-system/components/paragraph-title/paragraph-title-md.html`.
