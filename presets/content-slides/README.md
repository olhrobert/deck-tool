# Content slide presets

Copy one file into `decks/{deck-name}/` and replace placeholder text only. Do not change HTML structure, classes, or asset paths.

Use the same footer preset across every content slide in a deck.

## Presets

| File                    | Layout                                                                 |
| ----------------------- | ---------------------------------------------------------------------- |
| `content-slide-01.html` | Header + content + footer. Fact row, section title, body, alert. Uses `footer-01`. |

## Placeholders to replace

- Slide title pre / main / sub
- Quick-fact card labels, values, and meta
- Section title and body copy
- Alert title and description
- Footer disclaimer and slide number

## Example prompt

> Create `decks/q3-review/`. Copy `presets/content-slides/content-slide-01.html` to `02.html`. Title: "Project overview". Fill the three fact cards, then replace body and alert copy.
