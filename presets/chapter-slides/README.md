# Chapter slide presets

Layout examples loaded by the showcase. Do not change HTML structure, classes, or asset paths when editing.

Chapter slides use `<slide kind="cover">` with a `<slide-footer>` at the bottom (not inside `<footer-container>`). Canvas follows the brand cover color-theme.

## Presets

| File                    | Sidecar | Layout                                                           |
| ----------------------- | ------- | ---------------------------------------------------------------- |
| `chapter-slide-01.html` | `.md`   | Title + body stacked mid-left; cover footer with brand logo      |
| `chapter-slide-02.html` | `.md`   | Title top-left, body bottom-left; cover footer with brand logo   |

## Placeholders

- `Chapter title`
- Body copy under the title
- Footer notes / deck title / chapter / page
